# 共享字段适配与回归

适用于普通新建、编辑以及节点授权的审批编辑。手机和桌面共享宿主表单值、校验、候选请求和提交控制器；本规范不改变字段权限或后端写入合同。先检查宿主字段注册表和已有 helper，将修复合并到共享层，避免只在某个审批页面补丁修复。

## 人员展示缓存

人员候选由既有授权接口读取，按已确认 DTO 将 ID、姓名和头像映射到公共 `MobileIdentityField`。头像有值显示照片，缺失时沿用包的确定性首字展示；不得为头像增加全量目录读取或本地猜测数据。

`value` 保存已提交 ID，`items` 保存当前搜索结果，`selectedItems` 保存已提交人员的展示信息，三者职责分开。必须覆盖初始人员只有 ID 或姓名、头像由候选稍后补全的情况：在候选到达时合并已选 ID 的展示缓存，不能只在 `onChange` 后才缓存。更新姓名/头像不写表单，不触发校验提交，也不改变已选 ID。

缓存按稳定人员 ID 合并并去重；后来的空头像不抹掉已知照片，同时为候选行和已选区提供完整信息。搜索替换候选、取消、重新打开均保留已提交人员的照片。只缓存已选人员，不把过去未选的搜索结果重新注入候选；当前请求的取消、竞态及失败仍由原请求层负责。

缓存仅在当前应用/身份/记录或任务/字段会话内有效，用 `scopeKey` 或等效生命周期隔离。清空及替换选择时删除无关项；会话切换销毁旧缓存和弹层草稿，不存为全局或持久缓存。单选确认、多选点击确定只提交一次 ID；搜索、取消和 metadata effect 不调用表单 `onChange`。

## 数值与样式

Number、Currency、Percent 复用 `component-usage.md` 的原文合同：保留 `rawText`，先校验格式、小数位数和已声明范围，再转换为有限数值或后端允许的纯数字字符串。正号及省略整数位的十进制输入（如 `+1`、`+1.20`、`.5`、`-.5`）同样合法，仍受精度和显式范围限制。`1.230` 按三位小数处理，不先 round/parse；0 有效，纯空白走空值校验，不擅自为负数、百分比比例或货币单位制定全局业务规则。

范围读取当前字段定义的 `validations.minimum`、`validations.maximum`，缺少某一边界时不补通用业务范围。用十进制原文精确比较上下限，不先将原文转为 `Number`，否则超大整数或高精度小数可能被舍入成边界值。边界本身的指数写法不意味着允许用户以科学计数法提交。

提交类型沿用已确认的写接口合同；读取响应中的数值字符串不能证明写接口也接受字符串。现有合同使用 `JSON number` 时，转换后应与其 JSON 数字表示做十进制数值等价检查；前导零、尾零及负零的文本差异不算丢失数值。转换会改变数值或下溢成零时，明确提示并阻止请求，不静默舍入，也不自行切换成字符串提交。后端已明确支持纯数字字符串时可以保留精度；两端继续共用同一序列化路径。

审批的必填回调和宿主提交保护分开：公共 `validateFields` 仅接收节点可编辑必填字段；已修改的可选数值同样要由宿主校验，在字段处提示，并在 provider 转换、上传及网络请求之前复核。仅阻止保存字段的动作；`RETURN` 不保存字段，保持空补丁且不受业务字段错误禁用。不得将隐藏、只读、未修改可选字段追加进必填校验，也不绕过任务授权。

手机普通可编辑值区沿用所在页面或内容区的背景，不单独添加字段背景色；常态和触控 hover/focus 下都不添加盒状边框、灰底或阴影，不套桌面悬浮容器。页面和内容区保留自身背景，不能将本规则解释为整体透明；CSS 的 `background: transparent` 可用于清除控件自带底色。规则只作用于宿主拥有的控件，移动包组件用公开 API，禁止覆盖私有 class。保留键盘导航的可见焦点，不统一 `outline: none`。附件、审批意见和弹层搜索区按各自规范，不能受全局去边框规则影响。

`:focus-visible` 不是输入来源判定：文本、数字、长文本输入在鼠标点击或触摸聚焦时也可能匹配它。需要“触控无框、键盘导航有提示”时，复用宿主输入来源辅助层，或参考标准示例的 `use-input-modality.ts`：已知 pointerdown 后抑制普通字段输入描边，Tab/Shift+Tab 恢复焦点提示；打字、方向键移动光标、输入法与浏览器组合键不误切为导航。初始及无已知指针操作时保留焦点提示，按 ownerDocument 共享监听并在卸载时清理；不改全局 DOM、不抢焦点、不拦截表单事件。不要仅按屏幕宽度、是否支持触摸或 CSS 伪类判定键盘操作，也不以手机无框要求覆盖弹层、搜索区等公共组件的焦点行为。

数字输入至少 16px、44px 触控高度，值区和输入本身均有主题定义的左右留白；金额前缀和百分比后缀紧贴数字，与数值整体靠右，长文本可收缩、不把符号留在满宽输入框远端。桌面保留原控件和 hover/focus 样式，不能被手机样式命中。

## 必须执行的回归矩阵

| 场景 | 操作及可观察结果 |
| --- | --- |
| 单选/多选 × 初始 ID/对象 | 详情先到，候选后到并补头像；没有用户确认也能回显，表单 onChange 为 0 次 |
| 搜索与取消 | 搜索换成其他人员，多选临时勾选后取消；连续两轮取消、重新打开，原照片保留、草稿丢弃 |
| 候选更新 | 同 ID 新响应缺照片时，候选行和已选区都保留照片；不重复候选，不复活未选人员 |
| 清空与隔离 | 清空、替换选择，切换 scopeKey；旧照片/姓名/草稿不串会话，确认只写 ID 一次 |
| 数值格式 | Number/Currency/Percent 的正号、省略整数位、超精度、尾零、科学计数、分组符、中间输入态、空白、0、负数及显式范围；原文保留且非法值不发送 |
| 范围与传参 | 上下限相等及越界、超大整数、高精度小数、转换下溢和指数形式边界；越界或丢失数值时不上传、不发写请求；合法值前端提交、Service 解析与转发保持一致 |
| 提交保护 | 已修改可选数值错误阻止 APPROVE/REJECT/SUBMIT；绕过按钮直接调用 provider 仍拒绝；RETURN 空补丁且不预上传附件 |
| 手机 | 320/390/767px：金额/百分比符号与短长数值紧邻、左右留白、输入至少 16px；页面/内容区原背景保留，字段不额外添加背景色或编辑盒边框，无横向溢出；错误和焦点可见 |
| 指针与键盘 | 真实浏览器分别鼠标点击/触摸输入及关联标签、正常打字、Tab/Shift+Tab 往返、再次点击；点击时 border、outline、box-shadow 均无框线，键盘导航可见，值和校验不变；不得用伪造 focus-visible 属性代替浏览器验收 |
| 桌面 | 1280px：原控件、悬浮背景、键盘焦点和校验不变；手机/桌面切换仅一份视图且值不丢失 |

在实际公共组件上验证初始值、搜索和关闭生命周期；只 mock 候选请求，不用假的选择器代替。纯 helper 测试验证不可变合并及原文精度，真实浏览器验证 hover、focus 与几何布局。文字/正则检查只能防止规范丢失，不能作为行为回归证据。真实 iOS/Android/WebView、软键盘和后台未验证时明确记录范围，不用桌面模拟代替。

## 标准示例来源

审批 npm 源仓库的 `examples/field-adapters` 提供人员缓存、原文数值适配、CSS 及真实组件回归，字段适配说明见该目录的 `README.md`。这些示例只用于宿主字段展示与校验；审批任务的字段定义、值及授权来源以 [当前节点元数据合同](../../make-app-approval/references/task-detail.md#元数据读取合同) 为准。

先核对安装包是否携带该目录及移动包公开入口；未发布的源码示例不能视为当前正式包已有能力。通过源码目录或已安装包的实际文件读取，不深导入未声明的 npm 子路径，不依赖某个人的绝对路径或本机 Skill 安装目录。

生成新 App 或维护既有 App 时，沿用这些合同及用例，复用项目已有实现。UI 注册表/候选/序列化属于宿主，公共组件的草稿交互或视觉缺陷修复到对应公共包；不能只在一个页面或本机 Skill 中沉淀修复。
