# URL 字段的跨端展示

适用于 Schema 明确为 `Make.Field.URL` 的值：普通记录详情、只读表单字段、手机列表卡片、审批任务／实例和独立页面复用同一归一化与展示规则。它不改变编辑／提交值、字段权限、请求或记录导航。`Lookup` 普通值仍是记录引用；只有字段元数据明确目标为 URL、且宿主已得到规范化 URL 投影时才按 URL 展示，不根据标签内容猜测类型。

## 值与导航

- 先在共享纯适配器中处理字符串或 `{ href/url/value, label/name }`，href 依次取 `href`、`url`、`value`，展示文字依次取 `label`、`name`、href。已有宿主扩展形状沿其合同处理，不把对象转成 `[object Object]`／JSON，也不把 URL 字段先格式化成普通 `text` 而丢失 href。
- 仅有效的 `http:`／`https:`、协议相对地址及站内绝对路径可导航。先去除首尾空白并解析，拒绝控制字符、反斜杠、非法地址、其他协议及含账号密码的地址；站内路径不能被解释成外部协议。不能只用宽松的 `startsWith('/')` 或正则前缀将危险值放行。链接字段不沿用附件预览允许的 `data:`／`blob:`。
- 有文字但 href 无效时，保留原文字为普通文本，不提供点击／键盘导航及链接色；完全空值显示主题弱化的 `-`。不要为纯文本猜测并补 `https://`，也不要将无效 URL 隐藏为空值。
- DOM 展示使用语义化 anchor 及真实 href。外部链接默认在新标签打开，设置 `target="_blank"`、`rel="noopener noreferrer"`；沿用宿主已确认的站内导航策略。保留浏览器右键、复制地址和键盘 Enter 行为，不用只有 `onClick` 的 span 代替。
- URL 点击仅打开 URL，不能同时触发卡片／表格行／详情导航、选择记录或表单提交。保留 Tab 焦点及可见 focus；只停止必要的冒泡，不对 anchor 一律 `preventDefault()`。列表卡片不要把 anchor 嵌入整卡 button／anchor，改用语义合法的独立详情入口并保留原操作。

## 外观与职责

DOM 链接复用宿主或已核验公共包的 Link 展示能力，显式消费当前主题链接色；不可依赖浏览器默认蓝色。Tailwind Preflight、CSS reset 和基础主题可能令裸 anchor 继承普通文字色，必须在实际样式加载顺序下检查 computed style。普通、hover、focus 及 visited 状态仍可识别为链接，键盘 focus 不被统一去边框规则抹除。

PC／平板详情中的 URL 沿既有全行布局，文字允许安全换行。手机保留左标签与右值槽，值区可收缩、长 URL 在值槽内换行并靠右，不能撑宽页面或跨越标签；卡片按自身布局安全换行。DOM 建议在所属公共组件设置 `min-width: 0`、`max-width: 100%` 和 `overflow-wrap: anywhere`，而非在 App 覆盖包私有后代 class。CanvasTable 使用公开绘图／点击 API，沿其蓝色、单行省略及仅溢出 Tooltip 合同；canvas 单元格不能通过插入 DOM anchor 修复。

已明确接入 [公共组件语义主题](public-component-theme.md) 时，Canvas 宿主自有 URL renderer 将默认蓝色替换为同一主题的语义链接色，经宿主颜色解析后交给公开 shape，并读取当前主题以便重绘；不在首次创建时闭包缓存旧色。单行省略、溢出 Tooltip、安全 href 与点击隔离保持原合同，未接入新主题的旧项目不要求迁移。

宿主拥有元数据、归一化、访问资格、卡片／记录导航及共享字段注册表。公共包维护自身可复用 Link／手机展示组件的公开能力；宿主优先使用已核验的公开宿主插槽与适配器，例如审批 `renderField`、手机右侧值槽，复用同一 URL 适配器和语义链接。兼容的正式版本升级仅在已获授权范围及兼容性核验内采用，核验实际 exports、声明和构建制品后再接入。

公开能力确有行为或安全缺口时，先说明受影响能力、页面和依赖；确需修改公共包但尚未纳入授权范围时，须单独与用户确认范围，只暂停依赖该缺口的部分，不阻塞无关宿主工作。不得用私有 DOM／CSS 覆盖绕过缺口，不虚构新 API，也不把未支持能力报告为已实现。纯主题差异按 [完整方案应用与差异记录](component-usage.md#完整方案应用与差异记录) 记为“公共包主题后续同步”，不因此要求改包或阻断宿主交付；手机仍只跟随主色／选中强调色，保留原控件、布局和 Make 标准。

源码候选、正式 npm 产物、安装依赖及 Skill 指导分别核对，不用生产依赖本地路径冒充发布。

## 验收

先补会失败的宿主行为回归，再修复；包行为／构建回归仅在包修改已另行纳入授权范围时执行。文档链接检查不能替代以下实际验证：

| 场景 | 可观察结果 |
| --- | --- |
| PC 详情、手机详情／卡片、普通只读字段、审批任务／实例及独立页 | 同一 URL 值保留 href 与 label，DOM 是可聚焦 anchor，点击打开目标且不触发所属记录动作；CanvasTable 保持公开 shape 点击路径 |
| 字符串、带 label 对象、空值、非法 URL | 合法值显示主题链接色；非法值保留普通文字且无 href；空值显示 `-`，不抛错 |
| 安全边界 | 大小写协议与首尾空格按规范化处理；`javascript:`、`data:`、`blob:`、控制字符、反斜杠、凭证地址及伪造路径不能导航 |
| 长查询串／中文 label × 320／390／767／1280px | 手机仍在右值槽中安全换行、无横向溢出；PC 保持原详情布局，表格沿其省略合同 |
| 基础样式先／后加载、主题切换、普通／hover／focus／visited | 实际计算颜色可识别为链接，长链接不裁切、键盘焦点可见；不要仅断言 class 存在 |
| 原有编辑与业务动作 | URL 输入、清空、保存 payload 和字段权限保持原合同，卡片打开详情、表格选择、审批动作各自只执行一次 |

真实浏览器布局、宿主 DOM 测试、包行为／构建及飞书真机结果分别记录；mock 的事件或尺寸替身不能写成真实页面通过。
