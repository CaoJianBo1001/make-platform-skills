# 宿主组合示例与交付门禁

所有新项目，包括 POC 和模板，在生成对象列表或手机普通新建 Lookup 前读取本页。这里解决宿主组合遗漏，不新增组件库、不改变 Make 字段或权限语义，也不更新 MakeDesign 和公共 npm 包。其他表单、详情、人员／部门、日期和附件继续沿各自规范及正式公共组件。

## 复制组合，而不是另写一份简化页面

随 Skill 分发的 [record-page-patterns](../assets/record-page-patterns/) 是受控展示片段。把需要的文件及相邻样式／声明复制到宿主已有组件目录，按其中说明接入；业务 query、候选请求、权限、路由、保存与预检始终来自宿主已有共享 Controller。示例没有业务记录、人员候选、服务端 API 或默认授权，不是可直接发布的完整 App。

- **列表搜索**：PC／平板使用所选主 UI 库，AntD 示例只用于 AntD 项目；用户选择 Arco／shadcn 等时换成该库等效受控搜索，不引入第二主库。手机用独立搜索展示，与 PC 共享 query 与应用搜索处理，接齐 [搜索事件](../assets/record-page-patterns/README.md#列表搜索事件)：输入、立即应用、组合开始／结束及取消都交宿主 Controller，保留1秒防抖、Enter／按钮立即应用及 IME 组合期间零请求。保留原 iOS 输入字号、触控和查询合同。仅搜索不生成高级筛选；高级筛选已触发时继续按 make-app-filter 组合。
- **手机列表／导航／新建**：列表卡片和空态共用页面层组合，搜索始终存在；创建资格由 Controller 决定是否传新建入口。有正常记录、初始空列表或搜索为空时都不能丢掉已授权入口。采用完整手机高度链，列表底缘与视口底缘一致；通过宿主自己的导航 wrapper 测量实际占高，使用公开样式参数避让。安全区已经包含在导航总高时不能再累加一次。导航／视口变化重新测量并清理观察器；不覆盖包内部 class，不只抬高 z-index。
- **手机卡片**：保留冻结的页面灰底／卡片白底、扁平无边框和阴影、8–12px卡片间距，以及至少44px的单条操作触控区。内容由已授权字段提供，不为凑卡片添加字段、状态或按钮。单条编辑／删除继续复用 make-app-actions 的资格和预检链，详情、新建、编辑仍为全屏任务路由；下拉刷新继续使用宿主原查询与刷新处理。
- **宿主原生字段值区**：文本／数字／URL 输入和普通选项／Lookup 触发器可复用 `mobile-record-value.tsx` 与相邻 CSS；包的公开值槽类只负责对齐，不能代替原生控件重置。示例保持宿主受控值与原回调，只补冻结的无框、右对齐、44px触控、16px输入、禁用及输入来源焦点；不替换包内日期、人员、部门、长文本或附件，也不改变普通单选与 Lookup 的提交规则。
- **普通新建 Lookup**：候选点选只更新打开周期的草稿，确定才一次回写表单，取消不回写；重开以最新宿主值初始化。使用公开 BottomSheet／确认栏组合，不能以普通单选的即时 onConfirm 代替“确定”，也不把单关系伪装成 multiple。只有目标真正可搜索才出现搜索；加载／失败／取消／迟到候选继续由宿主处理。已有普通编辑 Lookup 只读，审批节点例外仍沿审批合同。
- **手机强调色**：手机组件与宿主自绘头像／卡片操作／链接／焦点消费同一公开主题变量，名称见 [颜色接入](mobile-theme.md#默认品牌色接入)。不能用固定业务色覆盖方案；缺少颜色时仅沿已核验的正式移动默认，回退有来源，不带入 PC 表面。只传 [颜色投影](../assets/mobile-brand-theme.mjs) 输出，不向手机传 PC 字体、密度、圆角、背景或导航；普通单选和身份单选的即时确认规则不变。

这些模块可按宿主结构裁剪展示插槽，不能把未复制的默认组成解释为“不需要”。已有实现满足合同时不强制换组件；补等价行为和计算样式证据即可。明确的产品例外记录来源、适用区域及测试差异，不从样板项目自行创造例外。

## 字段标签必须连到真实控件

PC／手机都须把标签与可编辑控件接在同一份实际ID上。不要给adapter内部input另加`input-`等前缀，却让Form.Item或MobileFieldRow仍使用字段key作为htmlFor；可见文字不代表标签已生效，name、placeholder、外层class及独立aria-label也不能弥补点标签不聚焦的问题。adapter接到的id须转发到真正的input／textarea／选择按钮或公开可访问控件，不只放在包装器。

主库为AntD时，在独立字段子组件中生成稳定ID，同时交给`Form.Item htmlFor`及受控adapter的`id`；Form.Item继续负责value/onChange等原受控接线，不在循环内直接调用Hook。示例见[资产说明](../assets/record-page-patterns/README.md#字段标签与控件id)。其他主库沿其公开标签API处理，不额外引AntD；非原生ARIA控件用真实可见标签的id经aria-labelledby关联，焦点与交互另验。普通只读详情继续展示文本，不为验标签而改成disabled输入。

## 必须接进宿主默认测试

从实际安装 makeui 复制 [mobile-form-acceptance.mjs](../scripts/mobile-form-acceptance.mjs) 和相邻 [类型](../scripts/mobile-form-acceptance.d.mts)，同时保留 [原表单验收](mobile-form-acceptance.md)。实际字段／路由挂载使用正式公共组件、主 UI 库及真实宿主样式；只替换请求、授权等边界。

| 风险 | 需要的证据 |
| --- | --- |
| 悬浮新建被导航盖住 | 正常／空／搜索空列表的创建资格允许时各有一个入口，拒绝或任务页无旧入口；真实浏览器用 `assertMobileCreateEntry` 检查矩形、导航避让及命中，再真实点击验证路由；导航不产生记录写入 |
| Lookup 误用即时单选或键盘语义缺失 | 实际组件中点击／方向键选择候选后表单 onChange 次数为0；取消仍0；确定为1且是完整快照；重开读取当前宿主值。单选组有唯一可用 Tab 入口，方向键循环跳过禁用项，过滤／全禁用／空候选不清掉草稿、不抢搜索焦点。普通选项／人员单选另外验证即时回写，不能全改为确定 |
| 搜索遗漏或裸输入 | `assertListSearch` 验证真实可用的搜索；PC／平板用同主题官方主库控件作参照。真实组件另测1秒防抖、Enter／按钮立即应用并取消旧计时器、清空仅应用一次；IME组合中停留超过1秒或按Enter仍零请求，结束后重新计时，组合中卸载只取消不应用。跨 View 保留当前查询，搜索空结果仍保留授权新建；不能只查DOM里有没有 input |
| 错误主题变量被默认色掩盖 | `assertThemeColorsMatch` 用公开主题组件／参照比较自绘元素的已解析计算颜色；默认及两份不同主色逐个验证，不能将两个都回退默认色的宿主元素互相比对 |
| 卡片和点击范围退化 | `assertMobileCardBaseline` 比较来自实际冻结组合的非颜色样式、卡片背景与操作矩形；`assertMobileListBaseline` 另查灰页面及至少两张相邻卡片的真实间距。鼠标／触控可命中，操作至少44px，不以字体高度代替点击范围 |
| Make 标准或手机布局被方案覆盖 | 默认／方案在相同宽度、记录及控件状态下对比字体、字号、行高、表面、圆角、阴影、密度、导航和字段，非颜色漂移为失败；PC继续消费所选完整风格及 Make 表单／详情骨架 |
| 原生字段只加对齐class仍保留浏览器外观 | 宿主自己的input／trigger使用自有reset或复制值区示例，加载真实样式；真实浏览器用 `assertMobileNativeValueSurface` 或等价几何验证常态无框、44px、16px输入，指针无额外盒框、Tab仍有焦点，禁用及右侧长值换行保持。组件DOM测试另证受控事件/ref透传，不能拿默认25px输入或仅类名当通过 |
| 字段标签for与内部id不一致 | 实际Form.Item／MobileFieldRow经adapter挂载后，用`assertFieldLabelAssociation({label,control})`检查真实原生关联或公开ARIA关联；显式错误id必须让默认测试失败。浏览器点标签应聚焦相应原生输入，按实际角色读出名称；不拿另一个手写测试表单或placeholder替代业务字段 |

通过类型声明传入宿主真实元素，不依赖包私有类名。参照必须来自实际所选库或已加载的冻结组合，不复制错误实现当“基线”。门禁输入缺失、零矩形、无 hit-test 能力或未解析的样式不能跳过后报通过；DOM 环境不能证明几何时转真实浏览器。工具单测中的矩形替身只验证工具，不是 App 验收。每类至少恢复一次已知错误，确认默认测试或浏览器检查会失败，再恢复实现。

## 重新生成及浏览器回归

维护本组规则后，用新的空 POC 和仅预置依赖的新模板读取实际已安装版本，按原设计路线询问及交接规则生成；不要把旧失败项目修好后称为“重新生成”。先记录基线，使用两份明显不同的方案及主库默认主题验证列表、新建、编辑、详情。测试入口只放隔离环境，不加入产品换肤器／验收面板。

在320／390／767px及768边界实测手机列表、空结果、Lookup、公共字段和操作；补1199／1200及宽PC，保留共享草稿／查询，卸载Canvas旧选择。手机只变允许颜色，PC保留选定样式和布局。安全区非零与导航变化要测，固定位置不能被宿主 transform 等包含块意外改变。默认 test、类型检查、构建、真实浏览器和真机分别记录，不因自动测试成功掩盖不可点的新建入口或错误提交。

真实 Make/IAM、附件、iOS／Android／飞书、软键盘及发布按当前任务已有范围验证；没有条件时明确待验，不伪造通过。发现问题在当前授权内修复宿主与 makeui 指导／示例；公共包确有能力缺口才记录依赖，不能为这组组合错误默认扩改 npm 包。
