# 页面请求与大数据验收

已触发的分析需求在接入前读取；多图、跨对象、万级数据或页面变慢时重点核对。查询合并、授权快照、有界并发和分页预算由 [Service 聚合规划](../../make-app-service/references/aggregate-query-planning.md) 统一维护；本文件约束页面消费，不另造查询引擎。

## 从区块规划查询，不按组件逐个取数

先把本次卡片、图形、解释、明细对应到唯一统计来源。一个后端结果可以同时供多个卡片和图表使用；公共组件接收标准结果，不能每个组件各调用一次相同接口。分组汇总明细直接消费当前结果，业务记录下钻才使用另行设计的接口和权限。

单个聚合可组合同范围多指标，多来源用 createDashboardService 和已有派生／序列能力；不同单位只影响展示，不自动意味着必须多取一次。查询条件或业务群体不同则保留独立来源，不为减少请求合并分母。不要按每个部门、客户或月份循环请求可一次分组取得的数据。

初始化阶段无分析需求时仍不执行这些查询。需求已触发时，只加载当前区域、活动页签及其真正需要的依赖；隐藏页签和所有示范模板不在打开一个页面时一起请求。

## 初始化、目录与业务查询分开

| 资源／动作 | 页面规则 |
| --- | --- |
| 身份、权限、Schema | 复用宿主访问控制 Provider 和已确认的刷新代次，不在每个图表／页面另建初始化；服务端复用边界按 Service 合同 |
| 分析目录 | 只有组件实际需要 definitions、labels 等目录内容时加载；只消费工作台完整结果的页面不发送空用的 catalog 请求 |
| 可复用的授权目录 | 若宿主已有缓存，按 App、身份／访问代次、定义版本及完整路径／业务参数分区；失败不缓存，刷新／失效后重取 |
| 业务 query／comparison | 通用接入不跨请求缓存结果；显式查询、筛选变化或刷新需要读取当前业务统计 |
| 视觉主题、显示精度、弹层开关 | 不改变统计语义时只更新展示，不重新获取身份、Schema 或聚合 |
| 路由返回和页签切换 | 可复用同访问代次的合法元数据／目录；按需求重新查询该页业务结果，不预取所有页面 |

跨请求元数据复用须由宿主已有契约允许，不能只用客户端随机代次或 TTL 当作授权。不要把某个业务项目的 Header、缓存容量、并发值写进所有新 App；正常接入复用现有身份与权限链。

## 防止重复 effect 与过期请求

请求由一个明确的宿主控制器或稳定 Hook 拥有。规范化后的业务参数、App、身份、权限代次与刷新代次构成查询上下文；相同语义的状态恢复不应仅因新对象／回调引用再发一次请求。UI 滚动、展开明细或普通重渲染不触发统计。

复用包 Hook 时保持 transport 引用稳定；工作台／序列保留自身公开合同，不硬塞基础结果 Hook。沿用宿主筛选提交方式，编辑草稿值与实际执行参数分开；快速切换时取消已不需要的请求，晚到结果不能覆盖新上下文，身份或授权变化立即卸载旧结果。

取消须传到 Service 和实际网关读取，只忽略前端响应不节省后端工作。共享元数据的单个等待者退出不能取消其他等待者；正常请求结束不触发底层 abort。细节复用 [Service 取消合同](../../make-app-service/references/service-api-contracts.md#request-cancellation)。

分别在生产构建和开发模式记录请求。开发 StrictMode 重挂载需要与线上重复区分，但不能用它解释所有重复；检查真实在途取消、依赖变化、状态恢复、路由及刷新链路。

## 大数据展示与验收

不要为浏览器统计下载全部记录，也不把全部聚合组无预算地渲染。按用户问题选择日期粒度、系列数、Top N 或分组范围，保持分母和完整性不变；高基数超预算时给出可理解的限制与收敛建议。区分事实数量、返回组数、序列点数和 HTTP 体积，公共包容量不等于性能 SLA。

每类页面动作记录 UI 请求和下游调用预算，实际接入测试至少覆盖：

- 首次初始化、同上下文查询、筛选、路由返回、显式刷新分别计数；页面不使用目录时请求数为零，打开汇总明细不新增业务查询。
- 多卡／多图共享结果，兼容指标合并；重复总体来源在单次执行中去重，业务重新查询仍读取最新结果；不同条件／参数不错误合并。
- 大量事实通过聚合返回少量组；另测多维高基数分页和预算，不能仅用“万条数据能显示”代表全部性能场景。
- 请求内共享快照保留必要复核；身份隔离、权限变化、刷新、失败重试、单个／全部等待者取消均正确，不能出现挂起或旧值回写。
- 相同口径的优化前后答案、NULL／零分母和完整性一致；记录响应字节、最大在途量及 UI 渲染，区分等待接口与图形渲染开销。

验收保留真实请求计数和相同 Trace 的耗时；总路由数少不等于下游调用少。局部顺序测试、真实页面核对和多用户压测分别记录，不承诺所有行业、数据规模和网关环境都有相同响应时间。
