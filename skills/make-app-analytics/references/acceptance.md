# 接入验收与典型任务

把“Skill 能指导任务”“接入产物符合合同”“真实数据核对”“页面已验收”分别记录。metadata lint、文档存在、人工写出的固定定义通过测试，都不能证明其他 Agent 已独立完成自然语言任务。

## 基础任务的最小产物

使用任务原文、必要 PRD 口径、授权 Schema 和有来源的统计结果进行演练。示例字段及状态值须映射真实模型，不将下面的期望数值或状态作为跨 App 默认。

| 请求与已知上下文 | 应形成的接入产物 | 验收要点 |
| --- | --- | --- |
| 在回款列表加月度回款趋势；已确认口径为已到账金额、按回款日期 | 嵌入折线；Date 按月、sum 金额，基础条件限定已到账及日期非空 | 使用真实状态底层值；未返回月份不补零；金额单位可查证；不顺带创建客户／售后模块 |
| 在客户列表加客户来源分布，按全部客户记录数看占比 | 完整来源分组 count；少量互斥非负分类时使用环图 | 不取 Top N 冒充完整占比；不按同名客户去重；缺失来源显式保留或说明 |
| 在售后列表只加待处理工单数；现有口径明确仅待响应 | 无维度 count 指标卡，基础条件限定已确认的待响应状态 | 不引入整页看板；不将当前明细页长度当总数；只查询对应对象 |

如果第三个请求未定义“待处理”，且 PRD 也没有口径，先询问仅待响应还是包含处理中；确认后再形成定义。不要默认把 `open` 当作所有项目的待处理状态。

### 负向和边界任务

- 只有客户录入、审批和搜索的初始化 PRD：不执行统计探查，不增加分析依赖或入口，也不询问是否加看板。
- 初始化 PRD 已要求月度经营概览：与业务范围一起规划必要指标，不以“初始化默认不启用”为由漏做明确需求；没有要求的对象不顺带建设。
- “工作台”仅表示业务入口或待办：沿用原壳层，不自动加统计。已有页面追加一张趋势图时只查询相应对象，不生成整套分析中心。
- “导出本月订单报表”且明确为明细 Excel：沿用导出流程，不因“报表”触发图形模块。
- 只要显示现有列表筛选后的总数：复用列表 total，不重复安装分析包或注册另一套计数链路。
- 已确认指标和位置的一张图：直接执行，不再次询问是否启用分析，不让用户选择图形或引擎。
- 日期只有一个有效桶：保留精确汇总，使用包的表格回退；不造出第二个时间点。
- Top N／部分分类、负值和全零构成：不画表示整体占比的饼图。
- 维度不支持聚合或字段不可见：不能换到未授权字段、默默去掉基础条件或用全量统计冒充目标口径。
- 指标名称有多种解释：先查 PRD／现有规则；仍有影响结果的歧义时询问业务口径，不把图表偏好当作必填问题。

## 自动化和真实核对

接入产物通过实际包的 validateDefinition、执行器和 resolveFixedPresentation；对条件编译、请求实体／字段、单位、覆盖范围及视图检查可观察结果。应覆盖无权限零聚合请求、客户端定义／CEL 篡改拒绝、基础条件字段缺失，以及固定图形失效时的处理。不得用只匹配 Markdown 中的关键词来代替这些测试。

真实验收通过既有宿主适配器，只读核对同口径全局值和分组值，注明来源、时间、覆盖范围及限制。构成图分组计数可与总计核对；月度与分类金额只在范围一致时比较。接口错误保留失败状态，不写成零。夹具与真实证据分开，不用硬编码的历史数量要求后续环境始终相等。

## 页面验收

- 在桌面常见宽度与宽屏中核对实际容器边界：页面外边距符合宿主密度，标题、页签、指标与图表外缘对齐；没有因居中限宽或重复 padding 导致的大块无效留白。手机重排后仍核对对齐与局部滚动。
- 按 [图表占位验收](chart-layout.md#交付前检查) 分别检查卡片、画布与有效绘图区；覆盖本次图形的少量分类、长标签、多系列、页签恢复和容器缩放。指标组不被高图拉伸，短表／回退／明细关闭不遗留大空框，尺寸调整不额外聚合。包内部留白缺少公开调整入口时记录能力缺口，不以覆盖私有样式通过验收。
- 同排同层级卡片核对上下边缘和已有页脚的底缘，覆盖不同图高、宽窄列及元信息换行；各行保留自身合理高度，不只把外框拉高。重复尺寸通知不累计补白，切到手机单列或数据回退后清除旧行补齐量；核对图例、数值和请求次数保持一致。
- 业务页面无复制自验证工程的常驻环境标记或演示提示；独立合成样例页保留数据来源。必要统计口径可通过问号完整阅读，错误、权限拒绝与部分结果没有被隐藏。
- 桌面及手机能完成阅读和核对；没有整页横向溢出、长金额挤压、说明遮挡操作或无法关闭的明细。
- 统计口径使用标题后问号、分条提示；紧凑数值能查看精确值；数值表头与单元格对齐；长表限制在所属容器滚动。
- 只挂载本次区域／活动主题的查询；切换与权限变化清除旧值及旧明细，晚到请求不覆盖新数据。
- 列表联动按 [筛选交接验收](list-filter-integration.md#验收) 检查：可映射条件的实际请求同范围，关键词、多选或复杂条件不能完整映射时零统计聚合，保留原列表筛选并清除旧分析结果。
- 覆盖加载、空数据、全 NULL、后端拒绝、登录过期和普通服务错误；授权导航仍可用，错误不能显示为成功统计。

若任务只写规则或验收产物，不修改 App 页面，则记录未进行新页面验收，引用已经核对的相同组件行为；不声称已经把新指标交付到 App。

## Skill 任务效果的进一步验证

后续独立任务给执行 Agent：实际用户请求、本 Skill、最小 PRD／Schema 及允许的数据源；不提供预选图形和预写分析定义。比较是否按需触发、规模是否合适、询问是否必要、真实请求是否保持口径，以及最终界面和测试。没有这类独立任务证据时，称为草稿／接入产物验证，不称为所有 App 的自动接入验收。


## 高级模板的额外验收

先核对安装制品的实际导出和锁文件完整性；能力基线与历史起点见接入合同。共同范围模板的分子／分母继承同一 scopes 注册，实际请求含相同基础过滤与日期；拒绝额外过滤分母、参数映射不一致、有效样本不是单字段非空、以及仅用 describeSource 声明同一字符串的绕过。

独立演练可选维修工单等不同对象，在原有列表上仅嵌入用户要求的条件占比、缺失情况和完整月份变化。给执行 Agent 用户原话、必要 PRD、真实字段结构与许可数据源，不给预写定义或期望数值。验证实际执行结果、未要求完整驾驶舱、没有前端统计、提示由 Service 返回、UI／Service 使用同一制品。模拟数据测试不冒充真实项目接口核对或浏览器验收。

金额 sum 型 Top N 未取齐分组时，实际总体请求必须同时含同字段、同单位的 sum 和 min；覆盖 min 缺失、NULL、负值及字段／单位不匹配被拒绝，min 为 0 或正数允许展示。count 与全分组可加性校验路径不强加 min。

## 分组序列和页面规划验收

用其他业务的必要 PRD、授权 Schema 和原始统计作为输入，检查下列任务。字段与标签由宿主定义，不把某行业状态或示例数值固化在包或 Skill 中：

| 任务 | 应核对的行为 |
| --- | --- |
| 部门与整体的月度指标对照 | 自行选择多系列折线或面积，基准可用虚线；同月同单位，整体独立去重，不累加重叠部门人数 |
| 两个来源计算月度比例或人均 | 注册 groupedSeries，检查真实时间条件及分母群体；保留缺月、真实零、NULL、零分母和未结束期间 |
| 期间切换为一个月再恢复 | 横轴随真实日期范围更新；单月回退表格且保留选中系列，恢复后图形与筛选一致 |
| 要求组成堆叠 | 只有宿主已确认组成互斥可加才声明 stacking；拒绝均值、重叠去重数、负值和当前不支持的百分比堆叠 |
| 初始化明确要求驾驶舱 | 形成宿主分析方案，覆盖问题、对象、时间、分母、来源、图形和验收；不默认把所有对象画一遍 |
| 目标或历史分母不存在 | 明确依赖，询问有业务影响的口径，不从当前总人数／样本生成目标或历史快照 |

新写配置先通过实际制品的定义校验、执行器、`evaluateGroupedSeries` 和图形模型检查；验证引用、单位和所选列一致。JSON Schema 通过不能代替实际聚合请求、时间与业务口径核对。

## 提示和明细的交互验收

- 按 [默认容器](integration-contract.md#汇总明细的默认容器) 逐一打开本次已有的基础图、多指标图和序列图明细：同一 App 的 PC 均为居中弹窗，手机均为底部弹层，不按图形或数据量混用抽屉；已有明确应用级约定时按该约定验收。
- 覆盖少列／多列、短表／长表及窄视口：宽度与内容相称且不越出视口，短表无大块空白，长表局部滚动，标题、关闭入口和表头保持可见，背景页面不滚动；宽表只在所属区域横向滚动。
- 原始记录下钻仍使用宿主原有详情／业务容器，保留权限、筛选、返回和操作链路；普通记录详情的 Drawer／手机任务页规范不套到分组汇总明细。图形失效时的行内结果表不主动弹窗。
- 打开、滚动及关闭汇总明细均不新增聚合或原始记录读取；关闭后焦点返回触发入口，图表尺寸与页面占位恢复，适配器更新需覆盖所有已有分析入口。
- 在真实手机尺寸打开明细，横向及纵向滚动：表头背景不透明，正文不穿过表头；选中系列的列没有丢失或悄悄增加。
- 桌面悬浮／键盘聚焦和手机点击均能打开列头问号及数值说明；检查完整展开后的内容，不能只确认按钮收到了点击。
- Tooltip 不被滚动表格裁剪，长解释能滚至末尾，位置在可见视口内；焦点打开后点击不会立即反向关闭。
- Portal 明细继承同一主题变量，亮／暗主题都有可读背景和文字；帮助层处于所属模态的焦点范围内。
- 按 Escape 先关闭提示、再关闭明细，并核对焦点返回；切换业务主题、筛选、刷新或撤权后不能留下旧数值和明细。

规则走查、示例执行、独立 Agent 任务、真实接口和浏览器验收分别记录。只维护 Skill 时，不把旧宿主的页面证据或模拟请求称为新页面验收。

## 接口调用与性能验收

按 [页面请求与大数据验收](query-performance.md) 和 [Service 聚合规划](../../make-app-service/references/aggregate-query-planning.md) 逐动作记录元数据、目录、唯一聚合、分页与补读次数，检查最大并发、响应体积、取消和答案一致性。同范围三张卡不应拆成三次总体查询，重复总体引用不重复执行；再次业务查询必须读取新值。核对实际 Service／网关调用，不能用一个 UI 请求或几万条演示数据替代下游调用预算、海量分组及并发性能验收。
