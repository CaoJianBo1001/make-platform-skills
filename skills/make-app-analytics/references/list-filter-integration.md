# 列表筛选与分析联动

列表旁新增卡片或图形，并要求统计当前列表范围时读取。筛选模型、关键词编译、Preset 及生效时机归 [make-app-filter](../../make-app-filter/SKILL.md)；统计注册和 API 归 [make-app-service](../../make-app-service/SKILL.md)。本参考只说明两者如何交接，不新增筛选 DSL 或通用转换器。

## 先确定统计是否跟随列表

位置相邻不代表统计范围相同。已有需求明确跟随列表时直接落实；明确为独立经营概览时保留独立范围并标明哪些筛选影响该区块。没有约定且两者会产生不同答案时，集中确认一次，不在每次筛选时询问。

跟随列表时，读取宿主已经成功应用的完整筛选快照，包括关键词、快捷状态、已生效高级条件及基础业务条件；不要只读取控件草稿或当前一页记录。空结果不代表空筛选。保留字段原始值、Lookup ID、运算符和 AND／OR 括号；不能把多个条件简化成第一个条件。

## 按实际制品选择接法

参数能力以 [制品合同](integration-contract.md#参数形状与日期边界) 为准。0.1.6 的注册参数仅提供 scalar 等值与 Date 字段的 dateRange；并不提供接受任意列表 expression 或条件树的 execute 参数。

| 已应用条件 | 可采用的接法 | 必须核对 |
| --- | --- | --- |
| 一个已注册字段的等值条件 | 映射到已注册 scalar 参数，Service 校验类型、枚举与资格 | 使用原始字段值，保留所有其他有效条件；数值 0、false 不按空值丢弃 |
| Date 字段的已确认左闭右开范围 | 映射到同字段 dateRange 的 `[start, end]` | 与列表真实起止边界及时区一致；不能擅自更换日期字段或把 DateTime 截为 Date |
| 关键词包含搜索、多选、非等值、NULL 判断、嵌套 AND／OR 或不兼容日期语义 | 先核验安装制品是否新增了公开且经过验证的对应入口；不能用现有 scalar 冒充 | 不将 contains 改成 eq、多选取首项、OR 改成 AND，或丢掉不能映射的条件 |
| 仅有已保存的原始 CEL，无法由现有公开 API 无损还原 | 保留原列表链路和已应用条件，明确统计联动的能力缺口 | 不用正则解析、手写 CEL 或重建另一套筛选引擎 |

只有**全部影响统计范围的条件均可等价表达**，才发送联动统计。由宿主现有编译／校验链确认完整映射，不能仅因一个日期或状态映射成功就声明同范围。分析 query 不接受客户端任意 CEL、定义或 baseFilter 覆盖；原记录列表的 `filter.expression` 合同保持不变，不能把分析参数限制套到列表接口。

完整高级筛选无法用现有公开参数表达时，不在各宿主复制通用转换或查询引擎。说明需要扩展公共包的受控筛选入口或评估既有 Service 的合法等价方案，明确参数、授权、共同范围和完整性合同，再按需求推进；当前能力不能伪装成已完成联动。

## 条件无法完整映射时

- 停止该条件下的联动统计，不退回更宽范围查询；列表继续使用已应用筛选正常读取。
- 取消旧统计，清除旧数值、图形和明细；在所属分析区域显示“当前筛选暂不支持统计”等宿主反馈，不显示成功 0 或继续展示旧结果。
- 不自动清空关键词、高级条件或 Preset，不改变列表筛选，不为了保留图形悄悄改成独立范围。
- 用户另行选择独立分析范围时，按新范围注册并明确说明；这属于业务范围决定，不是让用户选择图表。

这些是接入限制状态，不应伪造成功的 AnalysisResult，也不要求给公共组件添加未公开的 state。HTTP 错误或本地停止请求分别沿宿主已有合同处理。

## 查询、分母与生命周期

同一对象的条件比率或质量模板，把可联动条件放入共同范围，分子只追加该指标专属条件，分母不能另带筛选。跨对象序列按已确认业务映射各自来源的可比群体，不能把某实体的任意字段直接复制到其他实体。已应用快照、传入参数、实际下游条件和解释必须一致；没有合法映射时停止对应指标，不能只修改范围标签。

筛选成功应用后，将完整快照的语义标识纳入宿主查询上下文；失败或未提交草稿不切换统计。复用已有规范化与请求代次，取消旧请求、清除旧明细；晚到结果不能覆盖新筛选。筛选重置、对象切换、Preset 恢复及权限变化走同一链路。不同快照不共用业务结果，解释与明细复用对应的同一结果。

## 验收

- 简单已注册等值与日期范围：比较列表、总体及分子实际请求的完整条件，独立核对答案，包含 0、false 和边界日期。
- 关键词＋日期、多选、嵌套 OR 或旧 CEL 无法完整映射时：统计聚合为零次，没有扩大范围或成功 0，列表筛选和查询保留。
- 从支持条件切到不支持条件：旧请求收到取消，旧图形／数值／明细卸载，迟到成功也不显示；重新切回支持条件后按新代次查询。
- 分别覆盖筛选提交成功、失败、清除、对象切换和恢复；不能仅比较控件文字或前端参数，还要核对 Service 最终传给 Make 的条件。
