# Schema 变更验证

用于字段、关系及固定默认值迁移。复用当前已授权环境；不因文档示例切换账户、后端或应用。

## 目标与差异

在预览及后续写入前，从当前配置和远端读取确认后端 context、profile、租户、实际应用键及角色。应用代码 deploy 的 Beta 默认不代表 Meta/Data API 自动选择 Beta；不凭名称或固定后缀猜实际键。差异必须显示这些目标和实际增删改，只应用用户已确认范围；基线或目标变化则重新展示差异。

先定位当前安装的 `makecli` Skill，将 `MAKECLI_SKILL_DIR` 设为它的绝对目录；不要把本机路径写入项目 CI。其余变量由已核实配置赋值，不含凭证。使用随 Skill 分发的 Node.js 预览工具，沿用原 CLI 的认证与查询参数，只读预览单独执行：

<!-- schema-preview -->
```bash
node "$MAKECLI_SKILL_DIR/scripts/preview-schema-change.mjs" -f "$MAKE_SCHEMA_DIR" --context "$MAKE_SCHEMA_CONTEXT" --profile "$MAKE_SCHEMA_PROFILE"
```

原始 `makecli diff` 的退出码 `1` 既可能表示有差异，也可能来自登录、profile、参数或执行错误，不能单凭它判断预览成功。预览工具固定请求 `--output json`，共同检查原始退出状态、诊断输出及完整差异结果；只有 `appKey`、实体/关系列表、各项状态和汇总数量有效、相互一致且与退出状态相符时，才原样输出差异。合法空列表可为 `null`；格式依据已核对的 [CLI 0.5.21 公开实现](https://github.com/qfeius/makecli/blob/v0.5.21/cmd/diff.go)，其他版本结构变化须先核验，不能靠放宽检查猜测成功。

| 预览工具退出码 | 处理 |
| --- | --- |
| `0` | 已验证无差异；仍需核实工具识别新增属性，不能声称该属性已部署 |
| `1` | 已验证有差异；展示完整差异，确认仍在用户授权范围内后独立执行原 apply |
| `2` | 预览失败或结果未确认；停止，不进入确认应用步骤。包括原 CLI 报错但也返回 `1`、非空诊断、空/损坏/异常格式输出、汇总或状态不一致及进程中断 |

工具不调用 `apply`，也不自动修改资源。它只证明本次差异预览完成，不证明默认值支持、目标环境或业务变更已获授权。遇到诊断或未知格式，按当前 CLI 版本检查原只读命令的输出并解决原因，不静默丢弃诊断后放行。不要使用 `diff && apply`，也不要用 `|| true` 隐藏错误；已有明确授权按会话范围判断，不反复询问相同内容。

## 固定默认值能力

仅涉及 `defaultValue` 等条件性新属性时，应用前核实当前工具的差异及待发送载荷会保留该属性。版本号、`--help` 或命令执行成功不等于支持。优先使用已发布的转换/请求测试证据；缺少证据时可在隔离本地模拟端点检查真实 CLI 载荷，不为探测向真实环境写入，不猜测未公开的 dry-run 或草稿参数。

若字段被忽略或丢弃，停止依赖该工具的变更并说明缺口。需要改用 API 时，将已核实的 Meta 合同、目标实际应用键和精确载荷作为新的执行计划展示，确认仍在授权差异范围内；未核实的 API 不执行。不得为了验证而覆盖用户本地未提交 skill 或无关工具配置。

应用后逐项读回类型、选项、校验及字段顶层 `defaultValue`，再在获授权的测试范围验证缺 key 创建的实际结果。显式 null/空值与缺 key 分开，不把读取时补值、UI 预填或动作显式写入当作平台默认值生效。读回不一致或结果未知时停止后续步骤并报告已完成范围；不自动重发。此流程不保证平台原子性。

## 验证场景

| 场景 | 可观察的通过条件 |
| --- | --- |
| 原 CLI 返回 0 / 1 且有完整、一致的差异 JSON | 工具分别返回 0 / 1，保留差异及参数，均不执行 apply |
| 原 CLI 错误也返回 1，包括未配置 profile | 工具返回 2，无已验证差异输出，停止，不把错误当差异 |
| 原 CLI 返回 0 但空输出、错误信封或损坏 JSON | 工具返回 2，不因退出 0 声称预览成功 |
| 差异 JSON 与诊断、汇总或退出状态矛盾 | 工具返回 2，停止，不输出部分结果冒充完整差异 |
| CLI 忽略 defaultValue，diff 却返回 0 | 载荷核验发现缺失，不声称已应用、不执行依赖迁移 |
| 版本/帮助有命令但转换丢属性 | 判为工具能力不足，不以版本替代证据 |
| 用户要求 Beta，当前 Meta 键指向 Prod | 写入前报告目标不符；不根据 deploy 行为推断目标 |
| 切换到已核实 API | 展示相同业务差异的实际 API 计划，不捎带旧元数据修复 |
| 应用成功但读回缺默认值 | 停止，不继续宣称默认值生效或开启草稿 |
| 缺 key 创建与显式空值创建 | 分别验证；结果仅适用于实际验证的版本和环境 |

仓库脚本 `scripts/test-schema-change-guidance.mjs` 将 Skill 复制到含空格的独立安装目录，实际执行上面的预览工具和文档命令；模拟 CLI 覆盖错误与有效差异共用退出码 `1`、空值/异常输出、信号中断、参数保留和零写入。它验证的是预览边界，不证明真实 CLI 支持属性，也不代替实际平台验收。
